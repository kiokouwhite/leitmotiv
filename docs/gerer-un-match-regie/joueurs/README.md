# Scoreboard

Le scoreboard est l'élément central du stream : il affiche les deux joueurs, leurs personnages, le score et le contexte du match.

* [**Fonctionnement**](fonctionnement.md) — remplir le match : les joueurs, les infos et le score, depuis l'onglet Principal.
* [**Customisation**](customisation.md) — l'apparence : position, géométrie des cartes, couleurs, logo, particules.
