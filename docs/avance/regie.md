# Régie

La **Régie** (`/regie`) est une version **allégée** du panneau, sur **3 colonnes**, pensée pour piloter l'essentiel d'un coup d'œil pendant le live.

## Contenu

| Colonne | Ce qu'on y fait |
|---|---|
| **Start.gg** | Clé API, recherche du tournoi, choix de l'événement, **liste des sets** à charger |
| **Scoreboard** | Les joueurs et le score du match en cours |
| **Contrôles** | Affichage rapide / actions courantes |

En haut, des raccourcis vers le **Panneau complet** (`/control`) et les **Stream Deck URLs** (`/deck`), ainsi qu'un voyant de connexion.

## Quand l'utiliser

* Sur un **2ᵉ écran** ou une tablette, pour garder les sets start.gg + le score sous les yeux sans la complexité du panneau complet.
* Pour une personne du staff qui ne gère **que** le suivi des matchs pendant qu'une autre s'occupe de la mise en scène dans le panneau complet.

{% hint style="info" %}
La Régie et le panneau complet agissent sur le **même état** : ce que tu changes dans l'un se reflète dans l'autre et sur les overlays.
{% endhint %}
