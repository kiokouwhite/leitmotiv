# Infos du match

Ces champs de l'onglet **Principal** décrivent le contexte du match affiché en haut du scoreboard.

## Événement & phase

| Champ | Exemple |
|---|---|
| **Événement** | `Rêverie #4`, `Weekly SF6` |
| **Phase / Round** | `Pools A`, `Top 8`, `Winners Final`, `Grand Final` |

Quand tu charges un set depuis start.gg, la phase se remplit souvent automatiquement (round du set).

## Format du match

Choisis le format : **Bo1**, **Bo3**, **Bo5** ou **Custom**. Le format détermine le nombre de manches et l'affichage des scores (ex. « first to 3 » en Bo5).

{% hint style="info" %}
Pense à ajuster le format au round : les pools sont souvent en **Bo3**, les phases finales en **Bo5**.
{% endhint %}

## Logo central

Un logo peut s'afficher au centre du scoreboard, entre les deux joueurs :

* colle une **URL d'image**, ou
* **uploade** un fichier depuis ton PC.

Tu règles sa **taille** et son **opacité**, et tu peux le **masquer** complètement. Quand il est masqué, le bloc central disparaît proprement (pas de carré vide).

{% hint style="warning" %}
Le logo uploadé est stocké dans `public/uploads/`. Ce dossier **n'est pas** sur GitHub : pense à le sauvegarder si tu changes de PC. Un logo enregistré dans un [preset](../apparence/presets.md) est bien conservé avec le preset.
{% endhint %}
