# Commentateurs

L'overlay **Casters** (`/casters`) affiche les noms et réseaux des personnes aux commentaires.

## Remplir les casters

Dans l'onglet **Principal**, section Casters, pour chaque commentateur (2 par défaut) :

| Champ | Rôle |
|---|---|
| **Nom** | Le pseudo affiché |
| **Twitter/X** | @handle |
| **Twitch** | chaîne |
| **YouTube** | chaîne |

Seuls les champs remplis s'affichent.

## Disposition

* **Ligne** : les casters côte à côte.
* **Colonne** : empilés verticalement.

Choisis selon la place disponible dans ta mise en page OBS.

## Sauvegarder / charger un caster

Tu peux **enregistrer un caster** (nom + réseaux) comme preset pour le recharger en un clic à la prochaine soirée, au lieu de tout retaper. Cherche les boutons *Sauvegarder / Charger un caster* dans la section.

## Afficher / masquer

Utilise le bouton de visibilité, ou une [animation d'entrée/sortie](../avance/animations.md) pour un rendu propre.

{% hint style="info" %}
Besoin d'un style totalement différent (formes, calques, couleurs) ? Le **Créateur de casters** (`/casters-custom`) permet de composer un layout sur mesure.
{% endhint %}
