# Fonctionnement

## Deux modes

| Mode | Comportement |
| --- | --- |
| **Compte à rebours** | Part d'une durée définie et descend jusqu'à `0:00`. Le plus utilisé : écran de pause, « retour dans X minutes ». |
| **Chronomètre** | Part de 0 et monte. Utile pour chronométrer une manche ou un temps de setup. |

## Les contrôles

Dans la section **Contrôles** du panneau :

* **▶ Start** lance le minuteur — le bouton devient **⏸ Stop** pour le mettre en pause.
* **↺ Reset** le remet à sa valeur de départ.
* La case **Visible** affiche ou masque l'overlay à l'écran.

Le temps courant est affiché **en gros à côté des boutons**, et le minuteur **continue de tourner** même si tu changes d'onglet dans le panneau.

## La zone d'alerte

Tu peux définir un seuil (**Alerte si <**, en secondes) : en dessous, l'affichage change de style pour signaler que le temps est presque écoulé.

{% hint style="success" %}
Combo classique pour une pause : le minuteur en **compte à rebours** sur un écran d'attente — les viewers savent quand ça reprend, et tu n'as rien à annoncer.
{% endhint %}
