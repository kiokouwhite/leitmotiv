# Minuteur

L'overlay **Minuteur** (`/timer`) affiche un compte à rebours ou un chronomètre.

## Modes

* **Compte à rebours** : définis une durée (min/sec). Le minuteur s'arrête à `0:00` et peut changer de style à l'approche de la fin (zone d'alerte configurable). Parfait pour un « pause, retour dans X min ».
* **Chronomètre** : démarre à 0 et monte. Utile pour chronométrer une manche ou un temps de setup.

## Contrôles

**Start** / **Pause** / **Reset**. Le minuteur continue même si tu changes d'onglet dans le panneau.

## Styles

| Style | Rendu |
|---|---|
| **Défaut** | Boîte avec fond |
| **Minimal** | Chiffres seuls |
| **Grand** | Très grand affichage plein écran |

{% hint style="success" %}
Idéal pour l'écran « BRB / Pause » : minuteur en mode compte à rebours + un fond, et les viewers savent quand ça reprend.
{% endhint %}
