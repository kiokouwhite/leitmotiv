# Head-to-Head & stats

Deux overlays « data » alimentés par start.gg, parfaits pour meubler les transitions entre les sets.

## Head-to-Head (`/h2h`)

Compare l'historique de deux joueurs.

1. Dans la section H2H du panneau, sélectionne **Joueur 1** et **Joueur 2** (parmi les entrants du tournoi chargé).
2. Clique **Calculer H2H**.
3. Leitmotiv récupère tous les sets déjà joués entre eux sur start.gg et affiche :
   * le **bilan** victoires / défaites,
   * le **pourcentage** de victoire,
   * les **personnages** les plus joués par chacun.
4. Clique **Afficher** pour l'envoyer vers l'overlay H2H dans OBS.

{% hint style="info" %}
Idéal juste avant un gros match : « X mène 3–2 dans leurs confrontations ». Ça donne un enjeu narratif au set.
{% endhint %}

## Stats joueur (`/player-stats`)

Affiche les statistiques d'un joueur sur l'événement en cours (parcours, personnage principal, etc.). Sélectionne le joueur, puis **Afficher**.

## Historique tournoi (`/tournament-history`)

Montre le **parcours d'un joueur dans le bracket** de ce tournoi (ses résultats round par round). Utile pour raconter la run d'un joueur arrivé en top.
