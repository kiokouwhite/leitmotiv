# Charger un set

Une fois le tournoi chargé (voir [Connexion](connexion.md)), tu remplis le scoreboard **sans rien retaper**.

## Depuis la liste des sets

1. La section start.gg affiche les **sets en cours / en attente** de l'événement.
2. Repère le set à streamer.
3. Clique **Charger le set**.

Résultat : les **deux joueurs** (tags, seeds, réseaux, parfois personnages) et le **round** se remplissent automatiquement sur le scoreboard. Les scores sont remis à 0.

## Depuis la file de stream (stream queue)

Si vous utilisez la **Stream Queue** de start.gg (les TO y mettent les sets à passer en stream), Leitmotiv peut lire cette file directement : tu vois les matchs mis en attente de stream et tu les charges dans l'ordre. C'est le workflow le plus fluide pour une régie.

{% hint style="info" %}
**Astuce TO** : sur start.gg, ajoute les sets à la Stream Queue dans l'ordre où tu veux les diffuser. En régie, il n'y a plus qu'à cliquer _Charger_ successivement.
{% endhint %}

## Vérifier avant de lancer

Après chargement, jette un œil au scoreboard :

* les **tags** sont-ils corrects (pas de faute, bon côté) ?
* le **format** correspond-il au round (Bo3 en pool, Bo5 en top) ? Voir [Infos du match](/broken/pages/3wLcf35ao8dflkxXcnWw).
* besoin d'**inverser** les joueurs pour coller à leur position physique ? Bouton ⇄.

## Enchaîner les sets

En fin de set : tu [reportes le score sur start.gg](reporter.md), puis tu **charges le set suivant**. Le scoreboard se remet à jour, scores à zéro. Pas besoin de tout ressaisir.
