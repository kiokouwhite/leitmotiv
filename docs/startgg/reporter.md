# Reporter le score

En fin de set, on renvoie le résultat sur start.gg. C'est **l'étape à ne pas oublier** : c'est elle qui fait avancer le bracket.

## Méthode standard (depuis le panneau)

1. Assure-toi que le **score final est correct** sur le scoreboard (boutons − / +).
2. Ouvre **« Envoyer le score sur start.gg »**.
3. La fenêtre liste les **games** correspondant au score saisi.
4. Vérifie le gagnant de chaque game (et le perso joué, si tu renseignes ces détails).
5. Clique **✓ Envoyer sur start.gg**.

{% hint style="warning" %}
S'il n'y a **aucun game** à envoyer, c'est que le score est à 0–0 : règle d'abord le score avec les boutons − / +.
{% endhint %}

Une fois envoyé, le set est marqué comme terminé sur start.gg et le bracket avance. Tu peux alors [charger le set suivant](charger.md).

## Choisir le bon set

Si le panneau ne sait pas quel set reporter, un **sélecteur de match start.gg** s'ouvre : choisis le set concerné dans la liste. L'option *« Cacher les sets non lançables »* filtre pour ne montrer que les sets réellement jouables.

## Méthode télécommande 3DS

Les joueurs peuvent reporter eux-mêmes depuis une **3DS** (ou tout appareil verrouillé sur cette page), sans toucher à la régie : choix du set, saisie du score game par game, envoi sur start.gg. Voir [Télécommande 3DS](../avance/remote-3ds.md).

## En cas d'erreur

Si tu t'es trompée de score après envoi, corrige directement **sur start.gg** (le site), puis recharge le set dans Leitmotiv si besoin. start.gg reste la référence.
