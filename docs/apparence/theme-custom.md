# Créer un thème custom

Le **créateur de thème** fabrique un thème réutilisable à partir de **4 couleurs**, d'une **police** et des **particules**. Le thème obtenu s'applique à **tous les overlays**.

## La palette à 4 couleurs

Tout le thème dérive de ces quatre couleurs :

| Couleur | Utilisée pour |
|---|---|
| **Principale** | Accents forts : bordures, titres, aura des cam, couleur principale des cartes |
| **Secondaire** | Accents secondaires : lueurs (glow), particules, dégradés |
| **Blanc** | Les textes clairs (noms, tags…) |
| **Noir** | Les fonds sombres (cartes, panneaux…) |

Change une couleur → tous les overlays se recolorent en direct.

## Créer le thème, pas à pas

1. Onglet **Customisation** → **Créateur de thème** (« Créer un thème custom »).
2. Règle les **4 couleurs** de la palette.
3. Choisis la **police** (font) du thème.
4. Choisis le **type de particules** (et coche *teinter selon le thème* pour qu'elles prennent tes couleurs).
5. Donne un **nom** au thème dans le champ prévu.
6. Clique **✨ Créer le thème**.

Le thème apparaît alors comme **carte** dans la liste des thèmes custom, avec son nom. Tu peux le rappeler d'un clic, plus tard, dans n'importe quelle session.

## Modifier ou supprimer

Survole la carte d'un thème custom : deux boutons apparaissent dans le coin.

* **✎ Éditer** : rouvre le créateur avec les réglages du thème ; refais tes changements puis **Créer le thème** met à jour le thème existant (il ne crée pas de doublon).
* **✕ Supprimer** : retire le thème de la liste.

## Aperçu (zoom / déplacement)

Le créateur affiche un **aperçu** avec des contrôles de zoom (`+` / `−` / reset) et déplacement, pour juger le rendu de près.

{% hint style="success" %}
Comme les couleurs custom pilotent tous les overlays, l'aura des **cam** passe en couleur *secondaire* et la bordure en couleur *principale*, le **cadre événement** prend le noir/principale du thème, etc. Un seul thème = une identité visuelle cohérente sur tout le stream.
{% endhint %}

{% hint style="info" %}
Un thème custom porte **couleurs + police + particules**. Si tu veux aussi figer la **disposition** du scoreboard, l'image de fond, le logo… enregistre en plus un [preset de scoreboard](presets.md).
{% endhint %}
