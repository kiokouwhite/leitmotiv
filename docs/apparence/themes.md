# Thèmes

Un **thème** change les **couleurs de tous les overlays en même temps** (scoreboard, cam, cadres, bracket, VS screen…). C'est le réglage d'apparence le plus global.

{% hint style="info" %}
**Thème ≠ preset.** Un *thème* = les couleurs (+ police + particules). Un *[preset de scoreboard](presets.md)* = TOUT l'aspect du scoreboard (disposition, positions, image de fond, logo…). On peut combiner les deux.
{% endhint %}

## Appliquer un thème

Onglet **Customisation** → section **Thèmes** → clique une carte de thème. Le changement est **instantané** sur tous les overlays actifs.

## Thèmes prédéfinis

Une vingtaine de thèmes sont fournis, par exemple :

| Thème | Ambiance |
|---|---|
| **Default** | Or chaud sur fond sombre (le thème de base) |
| **Cyberpunk** | Cyan néon sur fond très sombre |
| **Synthwave** | Rose/violet rétro années 80 |
| **Midnight** | Bleu nuit profond |
| **Fire / Water / Eco** | Élémentaires (rouge / bleu clair / vert) |
| **Transparent** | Fond semi-transparent, pour compositions avancées |

## Et si aucun ne convient ?

Crée le tien avec le **créateur de thème** : tu choisis une palette de 4 couleurs, une police et des particules, et tu l'enregistres comme thème réutilisable. Voir [Créer un thème custom](theme-custom.md).

{% hint style="warning" %}
Appliquer un thème prédéfini **désactive** un éventuel thème custom en cours (et inversement). Les deux ne se cumulent pas : c'est l'un **ou** l'autre.
{% endhint %}
